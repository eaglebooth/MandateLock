# Logo-derived design system

- Palette: institutional navy `#0D2857`, deep navy `#071934`, security emerald `#00B985`, ice cyan `#E7F8FC`, white and cool blue-gray borders.
- Visual language: official governance dossier, signed ledger, document security. Avoid generic Web3 gradients and floating cards.
- Composition: large editorial headline, oversized logo seal, vertical execution procedure, authoritative readback ledger.
- Typography: Manrope for editorial clarity; DM Mono for addresses, states, evidence and procedural labels.
- Shape: mostly square document panels with small radii; large radius reserved for the supplied logo and circular security stamp.
- Feedback: green only for verified state; red for stopped transaction; success never shown before finality plus readback.
